# Platform scope

| Platform | Status in this gate |
| --- | --- |
| **Windows x64, SDL3** | built, tested, packaged |
| **Windows x64, SDL2** | built, tested, packaged |
| Linux x86_64 (SDL2 / SDL3) | **not built, not packaged, not certified**. testing-7's Linux packages are **not** reused or renamed. Community reports on testing-7 (openSUSE Tumbleweed) do not certify testing-8 |
| macOS, Android, ARM | out of scope |

**Hence, if testing-8 is published from this gate, it must be announced as a *Windows-only experimental testing release*.**

The machine is Windows 11, one display (3440×1440). Multi-monitor behaviour is not tested and not claimed.
